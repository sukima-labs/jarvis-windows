# J.A.R.V.I.S para Windows

Asistente de escritorio en español, mantenido por **Sukima Labs**. Usa Gemini como backend y una interfaz HUD para voz, conversación, métricas del sistema y vigilancia visual rotativa.

## Inicio rápido

1. Instala Python 3.10 o posterior.
2. Instala las dependencias: `pip install -r requirements.txt`.
3. Copia `config/api_keys.example.json` como `config/api_keys.json` y añade tu clave de Gemini.
4. Ejecuta `start.bat`.

`config/api_keys.json`, la memoria local, el entorno virtual y los audios personales se excluyen de Git. No subas claves ni archivos de memoria.

## Medios de la interfaz

El repositorio incluye las animaciones de Iron Man bajo Lottie Simple License y sus créditos en `assets/ATTRIBUTIONS.md`. Los GIF de películas y los medios personales se conservan localmente, pero no se redistribuyen desde este repositorio.

## Marca

El isotipo maestro es `isotipo_color.svg`; los iconos de Windows están en `assets/`.
